# Cadastro de Clientes (CRUD) 

Aplicação de cadastro de clientes com operações completas de Create, Read, Update e Delete, desenvolvida com HTML, CSS e JavaScript puro.

Veja o projeto <a href="https://milennafeijo.github.io/cadastro-de-clientes-crud/"> aqui </a> 

## Funcionalidades

• Cadastrar novo cliente via modal <br>
• Listar clientes em tabela dinâmica <br>
• Editar dados de um cliente existente <br>
• Excluir cliente <br>
• Persistência de dados com localStorage <br>
• Layout responsivo para mobile, tablet e desktop <br>

## O que aprendi

• Manipulação do DOM com JavaScript <br>
• Abertura e fechamento de modais via classList <br>
• Eventos de clique, submit e teclado <br>
• localStorage — salvar, buscar e atualizar dados <br>
• JSON.stringify e JSON.parse <br>
• Lógica de CRUD com array e índices <br>
• Responsividade com media queries <br>
• Uso de IAs [Claude, Copilot e ChatGPT) como ferramenta de apoio ao aprendizado <br>

## Desafios

• Entender o que cada parte do CRUD realmente faz <br>
• Controlar o índice correto para editar e excluir o cliente certo <br>
• Responsividade — transformar a tabela em cards no mobile <br>

## Tecnologias

• HTML5 <br>
• CSS3 <br>
• JavaScript
